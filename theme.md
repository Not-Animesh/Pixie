# Pixie UI Theme

Pixie uses a fresh, softly cozy light interface designed for calm productivity. Avoid dark, heavy surfaces and oversaturated page backgrounds.

## Palette

- Base: warm off-white `#f8f7f3`; panels `#fffdf9`; soft stone borders.
- Primary: violet for primary actions and selected navigation.
- Accent colors: sage/emerald, sky, lilac, coral, amber, and teal. Use them for small icon surfaces, status, and visual hierarchy—not large background fields.
- Text: warm charcoal for primary copy; muted stone for supporting copy.

## Type and spacing

- Use the system sans-serif stack, compact labels (10–13px), and clear heading weight.
- Prefer 8px-based spacing, 8–12px control radii, and 16px card radii.
- Keep sidebar rows compact at 36px tall and section labels small, uppercase, and low contrast.

## Components and interaction

- Surfaces use subtle borders and very soft shadows; avoid strong elevation.
- Selected sidebar items use a pale violet field with violet text.
- Interactive elements must expose hover and keyboard focus states.
- The desktop sidebar animates between full and icon-only modes. Icon-only controls must provide accessible labels and tooltips.
